# ui-design

## Scope
Designing and implementing user interfaces, dashboards, and operator controls.

## Guidelines
1. **Accessibility**: Follow WCAG guidelines. Ensure proper ARIA labels, focus management, and color contrast.
2. **Responsiveness**: Ensure the UI works on various screen sizes and devices.
3. **Consistency**: Use the established design system and component library. Avoid inline styles.
4. **Feedback**: Provide immediate visual feedback for user actions (e.g., loading states, success/error toasts).

## Verification
- Test the UI with keyboard navigation and screen readers.
- Verify layouts across different viewport sizes.
