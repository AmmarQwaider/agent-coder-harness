# Token Efficiency Rules

You must operate with maximum token efficiency. Adhere to the following rules at all times:

1. **Plan First**: Never write code immediately. Always write a concise, step-by-step implementation plan. Wait for explicit user approval before proceeding to execution.
2. **Compressed Output**: Never rewrite entire files unless absolutely necessary (e.g., creating a new file from scratch). Output only the exact lines changed using surgical search-and-replace blocks or unified diffs. Include enough context (a few lines before and after) to ensure accurate replacement.
3. **No Conversational Bloat**: Do not include tutorials, introductions, apologies, or generic conclusions. Output only the necessary information, plans, or code modifications. Get straight to the point.
4. **Avoid Glob Searches**: Do not list directory contents recursively or read massive amounts of files blindly. Rely on `repo-map.md` and targeted searches.
